# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing Blinkit's sales data using Microsoft Power BI. An interactive dashboard was developed to evaluate sales performance, product categories, outlet characteristics, and customer ratings to generate meaningful business insights.

## Key Performance Indicators (KPIs)
- **Total Sales:** $1.20M
- **Average Sales:** $141
- **Total Items:** 8,523
- **Average Rating:** 3.9

 ## Dashboard Insights
- **Sales Analysis:** Analyzed total sales by item type and fat content.
- **Outlet Analysis:** Evaluated sales performance across different outlet sizes and locations.
- **Product Performance:** Identified top-performing item categories based on sales.
- **Outlet Establishment:** Analyzed sales trends based on outlet establishment year.
- **Rating Analysis:** Evaluated average customer ratings across outlet types.

  ## Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Interactive Dashboard Development

  ## Key Features
- Interactive filters for Outlet Location Type, Outlet Size, and Item Type.
- KPI cards for tracking overall business performance.
- Multiple charts and tables for comparative analysis.
- Dynamic dashboard for exploring sales trends and outlet performance.

  ## Project Objective
    To analyze Blinkit's sales performance, understand product and outlet trends, and transform raw data into actionable business insights using Power BI.
